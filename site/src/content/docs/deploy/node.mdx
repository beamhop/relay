You'll end up with beamhop running on **Node.js 22 or newer**, from a single bundled `cli.js` file with the admin app next to it. Choose this if your servers already run Node and you'd rather not add Bun to them.

## Run it with npx

The quickest way: run the latest build straight from GitHub. Every push to `main` builds the Node bundle and publishes it to the repository's [`dist` branch](https://github.com/beamhop/relay/tree/dist), and `npx` can run it from there. You only need Node 22 or newer.

```sh
npx github:beamhop/relay#dist init
npx github:beamhop/relay#dist admin add npub1… --role owner
npx github:beamhop/relay#dist start
```

`init` writes `beamhop.config.json` in the current folder, and `start` serves the relay and the admin app on port 3334. Open `http://localhost:3334/admin/` and sign in with the owner key.

For a server, install it once instead of fetching it on every run. Run the same command again to upgrade:

```sh
npm install -g github:beamhop/relay#dist
beamhop start
```

<Aside type="note">
beamhop isn't published to npm. Always use the `github:beamhop/relay#dist` form; an npm package called `beamhop` isn't ours.
</Aside>

## Build it yourself

If you want to build from source, you need Bun on the machine where you **build** it. The machine that **runs** it only needs Node.


<Steps>

1. Clone, install and build:

   ```sh
   git clone https://github.com/beamhop/relay.git
   cd relay
   bun install
   bun run build:ui
   bun run build:node
   ```

   You'll find the result in `packages/server/dist/node/`:

   - `cli.js`, the whole server in one file
   - `verify-worker.js`, used when signature checking runs on worker threads
   - `admin-ui/`, the built admin app
   - `package.json`, listing the few native dependencies

2. Try it right there:

   ```sh
   BEAMHOP_OWNERS=npub1… node packages/server/dist/node/cli.js start
   ```

</Steps>

### Run your build somewhere else

To run it on another machine, copy the whole `packages/server/dist/node/` folder there and install its dependencies:

```sh
cd /opt/beamhop
npm install --omit=dev
node cli.js init
node cli.js start
```

The only runtime dependencies are native drivers: `better-sqlite3` for SQLite and `postgres` for PostgreSQL. `sharp` is optional and enables image thumbnails. `npm install` builds or downloads them for that machine, so install on the same OS and CPU type that will run beamhop.

For a service that starts at boot, use the [systemd example](/relay/deploy/bun/#run-it-as-a-service-with-systemd) and change `ExecStart` to `/usr/bin/node /opt/beamhop/cli.js start`.

## How it differs from Bun

- SQLite goes through `better-sqlite3` instead of Bun's built-in driver. The database file is the same, so you can switch between runtimes.
- HTTP and WebSockets go through Node's `http` module and `ws`.
- Everything else, including configuration, the CLI and the admin app, is identical.
